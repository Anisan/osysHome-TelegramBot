# TelegramBot - Интеграция Telegram бота

![TelegramBot Icon](static/telegrambot.png)

Интеграция Telegram бота для отправки сообщений, приема команд и взаимодействия с пользователями через Telegram.

## Описание

Модуль `TelegramBot` предоставляет интеграцию Telegram бота для платформы osysHome. Он позволяет отправлять уведомления, принимать команды, обрабатывать сообщения и управлять пользователями Telegram.

## Основные возможности

- ✅ **Отправка сообщений**: Отправка текстовых сообщений пользователям Telegram
- ✅ **Обработка команд**: Обработчики пользовательских команд
- ✅ **Обработка сообщений**: Обработка входящих сообщений
- ✅ **Обработка обратных вызовов**: Обработка обратных вызовов inline клавиатуры
- ✅ **Управление пользователями**: Управление пользователями Telegram
- ✅ **История**: Отслеживание истории сообщений
- ✅ **Управление аватарами**: Загрузка и хранение аватаров пользователей
- ✅ **Система событий**: Обработка пользовательских событий

## Панель администратора

Модуль предоставляет комплексный административный интерфейс:

### Главный вид
- **Список пользователей**: Просмотр всех пользователей Telegram
- **Команды**: Управление командами бота
- **События**: Настройка обработчиков событий
- **История**: Просмотр истории сообщений
- **Настройки**: Настройка токена бота и параметров

### Управление пользователями
- Просмотр информации о пользователе Telegram
- Редактирование настроек пользователя
- Просмотр аватара пользователя
- Отслеживание последней активности

### Конфигурация команд
- Создание пользовательских команд
- Связывание команд с методами объектов
- Настройка ответов команд

## Использование

### Настройка бота

1. Получите токен Telegram бота от @BotFather
2. Перейдите в модуль TelegramBot
3. Введите токен бота в настройках
4. Сохраните конфигурацию
5. Бот запускается автоматически

### Создание команд

1. Перейдите в раздел Commands
2. Нажмите "Add Command"
3. Введите имя команды (без /)
4. Свяжите с методом объекта
5. Настройте описание команды
6. Сохраните команду

## Технические детали

- **Библиотека бота**: python-telegram-bot (pyTelegramBotAPI)
- **Polling**: Long polling для приема сообщений
- **Многопоточность**: Отдельный поток для polling бота
- **Хранилище аватаров**: Кэшированные изображения аватаров
- **Очистка истории**: Автоматическая очистка истории
