# TelegramBot - Первоначальная настройка

Практический сценарий запуска `TelegramBot`: от токена и регистрации пользователей до проверки работы и настройки прокси.

## 1. Настройка токена и запуск polling

1. Откройте админку и перейдите в модуль `TelegramBot`.
2. Откройте вкладку `Settings`.
3. В поле `Token bot` укажите токен от `@BotFather`.
4. При необходимости заполните дополнительные параметры:
   - `History days` - глубина хранения истории.
   - `Proxy URL` - прокси для Telegram API.
   - `Timeout (seconds)` - таймаут запросов.
5. Нажмите `Submit`.

> [!IMPORTANT]
> После сохранения настроек создаётся `telebot.TeleBot(TOKEN, threaded=False)`, затем polling запускается в отдельном потоке.

---

## 2. Включение авто-регистрации пользователей

В `Settings` включите опцию `Auto register users` (`register=true`).

Поведение команды `/start`:

| Значение `register` | Результат |
| --- | --- |
| `false` | Пользователь не создаётся, генерируется предупреждение в уведомлениях |
| `true` | При первом `/start` создаётся `TelegramUser`, отправляется `Привет! Я телеграм-бот.` |

> [!WARNING]
> Если пользователя нет в таблице `TelegramUser`, основная обработка входящих сообщений и команд не выполняется.

---

## 3. Ручное добавление пользователя

1. Откройте `TelegramBot -> Users`.
2. Нажмите добавление пользователя.
3. Заполните поля:
   - `User ID` - Telegram chat id
   - `Name` - имя/ник
4. Для доступа к командам включите `Command` в карточке пользователя.

Дополнительно:

- `Say level` определяет порог входящих системных рассылок `say()`.

---

## 4. Проверка работоспособности

Чек-лист после запуска:

- [ ] Отправить `/start` боту.
- [ ] Убедиться, что в `History` появилась запись входящего события.
- [ ] Создать тестовую команду (см. `Commands.ru.md`) и получить ответ.
- [ ] Проверить, что у пользователя включен флаг `Command`.

Минимальный тестовый код команды:

```python
self.send_message(message.chat.id, "OK: бот отвечает")
```

---

## 5. Настройка прокси

Если Telegram API недоступен напрямую, укажите `Proxy URL` в `Settings`.

Плагин использует формат:

```python
telebot.apihelper.proxy = {"http": url, "https": url}
```

### Примеры строк подключения

| Тип | Формат | Пример |
| --- | --- | --- |
| HTTP | `http://host:port` | `http://proxy.local:8080` |
| HTTP + auth | `http://user:password@host:port` | `http://user:secret@proxy:3128` |
| HTTPS | `https://host:port` | `https://proxy.local:8443` |
| SOCKS5 | `socks5://host:port` | `socks5://127.0.0.1:1080` |
| SOCKS5 + auth | `socks5://user:password@host:port` | `socks5://user:pass@proxy:1080` |
| SOCKS5h (DNS через прокси) | `socks5h://host:port` | `socks5h://127.0.0.1:1080` |

> [!NOTE]
> Для SOCKS5 в зависимостях модуля используется `PySocks`.

> [!TIP]
> Если при SOCKS5 возникают SSL/DNS-проблемы, попробуйте `socks5h://`.

> [!IMPORTANT]
> При изменении `token`, `proxy_url` или `timeout` модуль перезапускает polling автоматически.
